## Frontloom Frontend Standards

Before writing any frontend code, read and follow these files:

1. `node_modules/frontloom/skills/frontloom-core-fe.md` — baseline quality standards
2. `node_modules/frontloom/skills/frontloom-react.md` — React / Next.js patterns

When these skills reference a file in `references/`, read it from `node_modules/frontloom/references/`.
Before finishing frontend work, review against `node_modules/frontloom/references/review-checklist.md`.
